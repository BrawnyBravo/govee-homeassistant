# Security Policy

## Reporting a vulnerability

Report privately through GitHub's advisory form:
https://github.com/lasswellt/govee-homeassistant/security/advisories/new

Do not open a public issue for a vulnerability.

## Scope

- The integration code under `custom_components/govee/`
- The release pipeline (`.github/workflows/`, release automation)

## Response

Reports are acknowledged within a few days. A fix is released once verified.

## Supported versions

Only the latest release is supported.
